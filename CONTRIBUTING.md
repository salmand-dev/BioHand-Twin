# Contributing

Contributions are welcome under the rules that keep this project's claims honest.

## Scientific rules
- **Never invent values.** Anatomical structures, attachments, moment arms, forces and joint limits need a retrievable source.
- **Label every number:** measured, derived, assumed or tuned. Do not mix them without saying so.
- **Do not call the model clinically validated,** or call a simplified actuator a complete physiological muscle.
- **A fit is not validation.** Do not count agreement with the data you tuned against.
- **Report failures.** Do not change a criterion to make a result pass. If a test horizon or criterion has to change, say so and keep the earlier result visible.

## Model data and licences
- **Never commit** upstream models, meshes, GLB files or other non-commercial geometry. They stay in the gitignored `third_party/`, `build/` and `godot_app/local_assets/`.
- **Never edit upstream files.** Changes are patches in `data/patches/`, generated by a script and validated on every build.
- New data needs a provenance record: source URL, version, author, licence, retrieval date, changes and redistribution permission.
- Use of the model is **non-commercial** (MoBL-ARMS licence).

## Working on the code
```bash
python -m pytest -q
```

```bash
python -m ruff check . --exclude third_party --exclude .venv --exclude build
```

```bash
python -m mypy simulation biomechanics --ignore-missing-imports
```

- MuJoCo is the only dynamics authority. The Godot viewer stays free of physics nodes.
- Use SI units and radians internally. Convert only for display.
- If you change a patch, task or glossary entry, regenerate the evidence with `scripts/reproduce_all.py` and update the affected report. Before committing, run `scripts/scrub_local_paths.py` so reports carry no local paths.
